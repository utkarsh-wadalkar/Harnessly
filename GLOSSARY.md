# HarnessArena glossary

| Term | Meaning |
| --- | --- |
| Harness | A coding-agent workflow that connects a coding model to tools and review controls. |
| Coding model | The model producing changes during a benchmark task. |
| Preference profile | A developer's confirmed priorities and must-have constraints, with a version and supporting interview evidence. |
| Hard constraint | A requirement a candidate must satisfy before it can be considered. |
| Soft criterion | A preference used to compare otherwise eligible candidates. |
| Candidate | A specific harness and coding-model combination. |
| Curated task | A maintainer-reviewed coding problem with a fixed starting state and objective grading. |
| Task family | Bug fix, feature implementation, test work, or refactoring. |
| Trial | An independent repetition of the same benchmark comparison conditions. |
| Attempt | One execution, including a separate execution caused by an infrastructure retry. |
| Evaluation plan | The candidates, tasks, conditions and maximum resource/spend limits proposed for approval. |
| Approval | A recorded acceptance of one exact evaluation plan. |
| Run manifest | The immutable record of a run's inputs and effective conditions. |
| Measurement | An observed result whose origin can be inspected. Missing observations remain unknown. |
| Grading | Objective evaluation of a submitted patch against protected acceptance checks. |
| Comparable runs | Runs sharing the declared comparison conditions, with disclosed capability differences. |
| Global benchmark | Controlled curated evidence eligible for public aggregate results. |
| Personal benchmark | Private evaluation selected for an individual's confirmed preferences. |
| Fit score | A deterministic summary of preference-weighted observed criteria after constraints are applied. |
| Typed decision | A choice from a finite set of permitted responses. |
| Pairwise decision | A comparison returning A, B, equivalent, or insufficient evidence. |
| Partial order | A comparison that leaves some candidates tied or unresolved. |
| Fallback | A clearly labeled deterministic result used when typed decisions fail or have insufficient evidence. |
| Evidence coverage | The portion of required evidence available for a decision. |
| Calibration | Held-out evaluation establishing whether a confidence claim is justified. |
| Replay | Inspection of previously captured, redacted evidence. |
| Live session | A quota-limited local evaluation conducted while the worker is available. |
| Provenance | Recorded origins and versions linking a claim to its evidence. |
| Publication | Explicit release of reviewed, redacted global evidence. |
