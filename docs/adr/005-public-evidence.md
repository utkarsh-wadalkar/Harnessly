# ADR 005: Curated evidence and explicit publication

Status: accepted for MVP.

Decision: accept only maintainer-curated tasks. Keep global and personal evidence separate. Public replay contains reviewed, redacted artifacts with explicit publication records; profiles and private prompts are excluded.

Why: public arbitrary repositories require stronger isolation and operational capacity than this MVP provides.

Tradeoff: restricted task intake limits breadth. Ten tasks across four families and two languages provide a reproducible starting point, with three trials per pair and prominent uncertainty.

Apache-2.0 targets original code subject to dependency/model review and third-party notices. Requires tickets 06, 15–18.
