# ADR 008: Original open-source release with evidence

Status: accepted release policy; dependency/model review pending.

Decision: target Apache-2.0 for original project code with compatible dependency review, third-party notices and adapted-source attribution. Release public GitHub and a reproducible reviewed replay/demo with original orchestrator, adapters, trace and decision behavior.

Why: the challenge requires meaningful open-source engineering and substantive AI use; configuration and unchanged forks are insufficient evidence.

Tradeoff: a license target does not establish compatibility of every dependency or hosted endpoint. Release must disclose missing runtime/evaluation evidence and distinguish recorded replay from live sessions. Publishing hidden graders, private profiles or credentials is prohibited.

Requires ticket 18 and [spec 08](../specs/08-release-traceability.md). The organizer URL/text location discrepancy and October 11, 2026, 5 PM IST deadline remain explicitly documented.
