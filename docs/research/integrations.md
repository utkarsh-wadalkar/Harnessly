## Minimal experiment protocol

1. Run host preflight; preserve failed checks. Docker controls must pass live smoke tests before coding agents run.
2. Build the pinned CPU LAYA source, record resolved dependencies/base/final image digests, download only typed weights, record hashes, and repeat an authenticated finite choice after an offline cache restart. Measure startup, peak resources and failures.
3. Freeze the 120 labeled development/calibration/test cases before evaluation. Include numerical tradeoffs and missing evidence; swap candidate order and measure cycles/abstention. Persist predictions, denominators, calibration provenance and actual latency.
4. Probe Gemma using non-personal scripted interviews under verified allowance and caps. Validate evidence spans, adaptive questions, conflicts, malformed output and provider failures; keep model usage/model ID evidence.
5. Execute OpenCode and Aider against one licensed curated fixture using one provider/checkpoint, three independent trials per pair, and a clean independent grader. Record conditions that cannot be made comparable.

No step has passed merely because its source supports it. Ticket evidence distinguishes offline fixture tests from live integration results.
